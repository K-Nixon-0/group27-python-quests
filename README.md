# Python Peer-Graded Assignment

## Project Overview
This repository contains our group's submission for the Python peer-graded assignment. The project is split among 6 team members, with each member completing 4 distinct tasks to meet the required total of 24 tasks across 6 difficulty levels.

## Project Structure
The repository is organized by difficulty levels as outlined in **Python Peer.jpg**:
* **Level 1 & 2:** Core Python syntax, basic loops, and variables.
* **Level 3 & 4:** Functions, conditional logic, and data handling.
* **Level 5 & 6:** Advanced problem-solving and structured programming.

## How to Run the Code
1. Clone the repository to your local machine.
2. Navigate to the specific level folder.
3. Run the Python scripts using:
   ```bash
   python3 filename.py
